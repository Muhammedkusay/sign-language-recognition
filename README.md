# Sign Language Recognition using LSTM

This project is a sign language recognition system developed using a Long Short-Term Memory (LSTM) neural network model.

The system recognizes hand gesture sequences and translates them into words. Currently, the model can identify the following gestures:

- Hello
- Thank You
- I Love You

The dataset was prepared manually, and the project was developed and trained in Jupyter Notebook.

## Features

- Real-time sign language recognition
- LSTM-based deep learning model
- Sequence-based gesture detection
- Custom-built dataset
- Word prediction from gestures

## Technologies Used

- Python
- Jupyter Notebook
- TensorFlow / Keras
- OpenCV
- NumPy
- Mediapipe
- Scikit-learn

## Model

The project uses an LSTM (Long Short-Term Memory) neural network to analyze temporal hand movement sequences and classify gestures into predefined words.

## Dataset

The dataset was manually collected and organized specifically for this project using recorded gesture sequences.

## Project Goal

The objective of this project is to facilitate communication through automatic sign language recognition using deep learning techniques.
